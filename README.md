# BioSignalXAI

BioSignalXAI is an AI-powered system for real-time detection and explanation of anomalies in biomedical time-series signals.
The project leverages Transformer-based sequence modeling and parameter-efficient fine-tuning (PEFT) techniques to analyze ECG data for anomaly detection. To improve interpretability and trustworthiness, the system integrates uncertainty-aware predictions and an LLM-based explanation module that translates model outputs into human-readable insights. The platform simulates real-time streaming inference through an interactive dashboard, demonstrating an end-to-end applied AI solution for biomedical signal intelligence.
